# Codex Reset Card 中文桌面面板

双击 **启动.vbs** 打开面板，使用 Windows 自带窗口与 Python 3.12 标准库，无第三方依赖。双击 **启动.cmd** 可在控制台观察启动错误。

## 已实现

- 悬浮窗显示自动使用时间和有效期到期时间（北京时间），提供“推迟 2 分钟再使用”按钮。每次从当前计划延后 2 分钟，只调整这张卡，最迟到有效期前 2 分钟。默认提前 5 分钟时，可延后到提前 3 分钟；再延后 2 分钟会越界，因此禁用。
- 临近执行的 30 秒、状态未确认、后台停止、已有执行/重试时不可推迟。操作期间禁止重复点击，结束后读回实际计划，失败时显示原因。操作期间需等后台恢复完成才能关闭面板。

- 右下角自动使用倒计时悬浮窗，每秒更新。主面板勾选“倒计时悬浮窗”显示或隐藏，勾选“悬浮窗置顶”选择是否覆盖其他窗口；默认开启，两项设置独立保存，重启或登录启动后恢复。悬浮窗右上角 × 可关闭显示，双击其内容可打开主面板。
- 倒计时使用后台已记录的自动触发时间（到期前 5 分钟），不是到期时间。未授权、服务停运、新卡未被后台发现、状态陈旧均有相应说明；到触发时间后等待后台结果，不声称已经成功兑换。
- 悬浮窗在主面板最小化后仍显示，关闭主面板则一起关闭。原有提醒弹窗会放在倒计时上方，避开任务栏并避免遮挡。

- 显示原工具授权、后台服务、提前量、可用卡数量、逐卡到期、计划触发时间、倒计时、最近动作与错误。所有日期使用北京时间，精确到秒。
- 每 30 秒执行 `status --json` 读取本地缓存；默认每 5 分钟执行一次 `status --refresh --json` 读取在线快照。任意两次在线请求至少间隔 60 秒，重启后仍节流。
- 普通失败按 5、10、20、40、60 分钟退避；遇到 401 / 403 / 429 暂停自动在线请求，处理原因后手动刷新成功会恢复。
- 在线读取失败保留上次成功快照，醒目标记“陈旧”；仍继续查询本地服务状态。未知卡数显示“未知”，不会当成 0 张。
- 原服务每天发现新卡。面板在线查询不会写入原服务计划；尚未被原服务记录或有效期发生变化的卡片，显示推算时间及“服务尚未记录”。原服务未授权或未运行时明确显示不会执行或计划待确认。
- 到期前 24 小时、1 小时、10 分钟提醒；启动时已进入多个阈值只提醒最紧迫一条。已兑换、已过期的卡不提醒，陈旧快照不触发新的到期提醒。
- 兑换结果、服务异常、读取错误提醒；“无需重置”“此前已兑换”与“本次成功重置”分开显示。
- 独立无阻塞 Windows 浮窗和可关闭的 Windows 提示音（不使用 Windows 通知中心 Toast）。最小化面板后仍能提醒；关闭面板后提醒停止，原服务继续运行。
- 提醒去重记录持久化，重复启动通过 Windows 命名互斥体防止多实例。第二次启动会提示检查任务栏。
- 默认窗口为 1160 × 900，小窗口可滚动查看内容；关闭面板与提醒生命周期说明固定在窗口底部。

## 范围与数据

常规显示使用 `status --json` 和 `status --refresh --json`。面板另外受控读取本地调度状态，只提取匹配卡片的下次执行时间和是否正在执行，不保存或显示原始完整状态和幂等请求键。它不读取 `auth.json` 或 token；在线请求由原 CLI 使用现有账号登录完成。

只有点击“推迟 2 分钟再使用”时，才会暂停后台任务，获取原后台的同名互斥锁，重新核对最新计划，仅原子修改该卡的 `nextAttemptAt`，随后释放锁、恢复任务并确认进程运行。全局提前量、其他卡片和原有授权保持不变。不提供立即兑换命令，不调用消费接口。若计划已保存但后台恢复失败，会明确提示，需检查后台服务。

原版 `codexrc status` 的 `triggerAt` 仍是有效期减去全局提前量的推算值；延期后，实际时间为它与 `nextAttemptAt` 中的较晚者。本面板会合并显示这个真实计划，后台日志的“下一次唤醒”也可核对。

可执行文件路径来自原仓库 `runtimepaths.Default()`：`%APPDATA%\codex-reset-card\bin\codex-reset-card.exe`。Windows 系统代理若启用，会只映射到 CLI 子进程的代理环境变量；已有显式代理环境变量优先，不修改系统或全局环境。

面板自己的设置、脱敏状态快照、最近 100 条历史和提醒去重记录保存在 `%LOCALAPPDATA%\CodexResetCardPanel\data`。启动时从磁盘恢复的快照标为陈旧，直到本次读取成功。在线快照超过 10 分钟、原服务缓存超过 24 小时，或任一读取失败时也标为陈旧。去重记录保留 180 天。

`--minimized` 适合由调用方配置登录启动；面板本身不创建快捷方式或自启动任务。面板运行于当前登录用户桌面，锁屏时提示是否可见取决于 Windows；电脑关机、面板关闭时不提供提醒，不保证系统通知中心投递。

## 演示与验证

双击 **演示.cmd**，或执行：

```powershell
python '.\desktop\reset_card_panel.py' --demo
```

演示数据、设置和提醒去重记录保存在独立的 `...\CodexResetCardPanel\demo` 目录。演示模式不启动原 CLI、不联网、不消费真实卡。面板里的“提醒测试”按钮只发本地测试提示。

```powershell
Set-Location '.\desktop'
python -m unittest -v
python .\reset_card_panel.py --smoke-test
```

`--smoke-test` 隐含演示模式，创建真实 Tk 窗口、三行卡片和测试提醒，验证后关闭并输出 JSON 测试结果。它不会验证实际卡片兑换或未来系统提醒投递。

## 源码

- `reset_card_panel.py`：中文窗口、后台只读读取、在线节流和退避、提示与声音。
- `panel_logic.py`：路径与子进程适配、脱敏数据、时区、缓存与提醒去重。
- `schedule_control.py`：单卡延期校验、跨进程互斥、原子保存、后台恢复及实际执行时间读取。
- `test_panel_logic.py`：未知状态、陈旧快照、已兑换/过期过滤、新有效期与旧计划错配、去重重启、结果误报和只读命令的回归测试。
